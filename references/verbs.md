# Design 27 — Steerable Studio Verbs

Load this module when the user steers an existing artifact with a targeted command (`polish`, `bolder`, `quieter`, `distill`, `clarify`, `harden`, `redesign`, `critique`) instead of asking for a greenfield build.

**Preservation Law:** Every verb except `redesign` preserves the incumbent brand palette, typography, product wiring, and factual content outside the requested scope.

---

| Verb | Intent & Scope | Concrete Moves | Hard Guardrail |
| :--- | :--- | :--- | :--- |
| **`polish`** | Final pre-ship craft pass on a mostly solid artifact. | Align spacing to `4px`/`8px` rhythm, fix nested radii (`max(outer - padding, 4px)`), balance heading orphans, tighten `tabular-nums`, verify `D27-Lock` and `prefers-reduced-motion`, run `scripts/d27-check.mjs --render` and `qa-and-critique.md`. | Never swap the brand palette, typeface, or macrostructure. |
| **`bolder`** | Amplify timid or static work (*Persuade / Experience / Motion / Thumbnails / Mascots*). | Inject **1 Diegetic Physical Artifact** frame or **1 Interactive Proof widget** (live scrubber, gain/parameter dial, or `#group` anatomy isolator) with an auto-play-once load demo; raise display-to-body ratio (`>= 4:1`, tight `0.86–0.96` leading); rewrite topic labels as **Assertion Headlines**; commit to one full-bleed or inverted focal band. | Never break Tier 1 contrast floors (`>= 4.5:1`), add decorative blobs/glows, or inject `scale(0)` / `ease-in` UI entrances. |
| **`quieter`** | Tone down noisy, over-styled, or fatiguing work (*Operate / Read*). | Strip unnecessary borders, shadows, pills, and repetitive section eyebrows (`<= 2` structural landmarks); replace rainbow accents with 1 focal signal + neutral ramp; calm surface tints; kill gratuitous looping animations. | Preserve clear hierarchy and interactive affordances (`:focus-visible`, active states). |
| **`distill`** | Cut visual and cognitive clutter to the core thesis. | Merge redundant sections, cut hero copy to assertion headline + 1 sentence + 1 primary CTA, collapse repetitive 3-col cards or `.ruled-row` boilerplate into a tighter spec matrix, remove filler visuals. | Never delete real product functionality, links, or user-supplied proof. |
| **`clarify`** | Exorcise AI hype, prose tics, and vague UI labels. | Purge AI slop vocabulary (*delve, tapestry, testament, pivotal, underscore, realm, vibrant, multifaceted, overarching*), negative parallelisms (*"It's not just X — it's Y"*), and throat-clearing openers (*"Moreover," "Furthermore," "In conclusion,"*); replace buzzwords (`supercharge`, `seamless`, `unlock`) and topic labels with concrete Assertion Headlines; strip `!` and `"Welcome back! 👋"`, add explicit comparison context (`+12% vs last month`), unify numeric precision. | Never invent metrics, customer counts, testimonials, or unverified claims. |
| **`harden`** | Make UI, SVG rigs, and reading layouts production-ready across edge cases. | Add `:focus-visible`, `prefers-reduced-motion`, cancellable load demos, empty/loading/error states, `overflow-x: clip`, `minmax(0, 1fr)`, `min-width: 0; overflow-wrap: break-word`, `>= 44×44px` mobile tap targets, `--m-fill`/`--m-cut` SVG cutouts, and RTL/long-string resilience. | Verify zero layout shift and zero horizontal scroll via `d27-check.mjs --render` at `390px`, `1280px`, and `1920px`. |
| **`redesign`** | Replace a heavily slopped or converged visual world while keeping product truth. | Inventory all existing routes, links, handlers, and real facts first; run `d27-deal.mjs` for a fresh Material World + Macrostructure + Diegetic Artifact; complete Stages 1–4 fresh with an `M·I·H·C·R` lock; verify zero lost content or wiring. | Never silently drop real features or fabricate replacement proof. |
| **`critique`** | Audit-only review with zero unsolicited edits. | Run `scripts/d27-check.mjs --render` (when runtime available) + `references/qa-and-critique.md` Passes 1–7, rank findings by Tier (*Floor / Reflex / Finish*) with exact `file:line` citations, and output the 6-line Art Director Sign-Off. | Report honestly; if there is no slop, say so and suggest at most 2–3 surgical refinements. |
